# Білети та відповіді — статична версія (GitHub Pages)

Це **окрема статична копія** сайту для публікації на GitHub Pages.
Робочий локальний проєкт (`../`) вона не замінює.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Сторінка сайту. Дані 30 × 10 **вбудовані** в неї, тому сервер не потрібен |
| `styles.css` | Стилі (копія без змін з робочого проєкту) |
| `app.js` | Логіка застосунку (копія без змін з робочого проєкту) |
| `.nojekyll` | Каже GitHub Pages не обробляти файли через Jekyll |

## Дані

Джерело — `build/tickets-data.json` робочого проєкту (30 білетів × 10 питань).
Файл **не змінювався**: його вміст вбудовано в `index.html`.

Щоб оновити дані на опублікованому сайті — запустіть у робочому проєкті
`powershell -NoProfile -ExecutionPolicy Bypass -File build-pages.ps1`
і завантажте оновлений `index.html`.

## Що працює

* **Режим 1** — повністю: вибір білета (1–30), автопошук за одним словом або
  комбінацією слів, накопичення результатів у Блоці 3, червоні роздільники 3 px,
  очищення Блоку 3.

## Що НЕ працює на GitHub Pages

* **Режим 2** — він потребує серверної синхронізації (`/api/state`, `/api/stream`),
  а GitHub Pages віддає лише статичні файли. Режим 2 у цій версії не
  використовуйте: перегляд результату з іншого комп'ютера працює лише
  в локальному проєкті через `npm start`.

## Публікація

Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)`.
